# Controle de saúde de ratos
Automatização de relatórios de saúde de ratos no biotério do laboratório de psicologia da UNESP Bauru. Os responsáveis pelos animais preenchem um formulário do Google diário com informações de peso e saúde para cada animal. O algoritimo limpa os dados do formulário, realiza análises e envia automaticamente para os cuidadores e superviores que trabalham no laboratório. 

_Esse projeto está sendo realizado com o apoio da Fundação de Amparo à Pesquisa do Estado de São Paulo (FAPESP). Nº de processo: 2023/14458-0_
